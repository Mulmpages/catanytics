# Overview

- Record a game of Catan via tui or website
- Analyse the game
- Export and Import the game

Currently, only the core class `Catan` is available.

# Installation

This python tool uses [uv](https://docs.astral.sh/uv/). Install uv and run `uv sync` to initialise a virtual environment. Use `uv run src\catanytics\...` to execute the programs.
